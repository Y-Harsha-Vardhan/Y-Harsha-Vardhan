## Projects

### [AI Chess Engine](https://github.com/Y-Harsha-Vardhan/AI-Chess-Bot)

A fully playable chess engine built from scratch around classic AI search techniques.

**Approach:** Minimax search with Alpha-Beta pruning, a hand-tuned static evaluation function (material balance, piece-square tables, mobility), and move ordering to improve pruning efficiency.

**Stack:**
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

**Highlights**
- Implements the full chess rule set including en passant, castling, and promotion
- Alpha-Beta pruning significantly reduces the search tree compared to plain Minimax
- Evaluation function designed by studying classical chess heuristics
