## Selected Projects

### [Freight CRM](https://github.com/Ganeshrane1234/Advanced_CRM) *(team repo)* — Production, paid engagement

Freight-forwarding CRM for a Mumbai logistics firm — paid freelance, 5 weeks, team of four, **live and in use today**. Owned the React 19 SPA architecture and ~50 of 124 endpoints end-to-end: enquiry board, agent dispatch with IMAP reminder loop, rates table with margin calculator.

Stack: React 19 · Node.js · Express · better-sqlite3 · GCP · Nginx · PM2

→ [portfolio writeup](https://y-harsha-vardhan.github.io/assets/writeups/freight-crm.html)

### [Quantitative Trading Models — Summer of Quant](https://github.com/Y-Harsha-Vardhan/SoQ-Project)

Systematic trading strategies backtested against real market data — IIT Bombay's **Summer of Quant**, **Top 10** finish. Walk-forward validation over in-sample curves; Sharpe and drawdown as the honest metrics.

Stack: Python · Pandas · NumPy

### [AI Chess Engine](https://github.com/Y-Harsha-Vardhan/AI-Chess-Bot)

Fully playable chess engine from scratch — no engine library. Minimax + Alpha-Beta pruning, hand-tuned evaluator (material, piece-square tables, mobility), move ordering to keep the search tree tight.

Stack: Python
